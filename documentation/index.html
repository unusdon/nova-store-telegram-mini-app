Nova Store — Telegram Mini App Store Kit

A complete, config-first e-commerce storefront + admin dashboard for Telegram Mini Apps. Pure HTML, CSS and vanilla JavaScript — no framework, no build step, no dependencies. Thank you for your purchase!

77 pages Storefront + Admin Dark & Light 3 languages (RTL ready) Telegram Stars · TON · Stripe Zero build step

This guide walks you from opening the files to publishing a live Mini App with your own brand, products, currency, languages and payments. Everything you'll change lives in one file — assets/js/config.js — so you rarely need to touch the page code at all.

Quick start

1

Unzip the package

Open the 01-html-css-js folder — that is the complete kit.

2

Start a local server

ES modules can't run from a file:// URL, so serve the folder over HTTP:

Windows: double-click START-SERVER.bat.   macOS: run START-SERVER.command.
Or use Python from inside the folder:

python -m http.server 8000
3

Open the store

Visit http://localhost:8000. Then hard-refresh with Ctrl+Shift+R after edits so you never see a cached page.

4

Make it yours

Open assets/js/config.js and change the brand, colours, currency and products. Save, refresh, done.

Testing outside TelegramEvery page is built to work in a plain browser too — Telegram-only APIs fall back gracefully (browser alerts, standard back button), so you can develop without opening Telegram at all.

Configuration

Open assets/js/config.js. It is one exported object, grouped and commented. Below is every block.

Brand

KeyWhat it does
name / shortNameFull and compact store names shown across the UI.
taglineSub-title under the store name.
logoEmojiQuick logo. Set logoSvg to use custom SVG artwork instead.
authorCredit line (defaults to unusdon).
supportUrlOptional external help/support link.

Theme

KeyValuesWhat it does
colorScheme'dark' · 'light' · 'auto'Default look. auto follows Telegram, then the OS.
allowUserToggletrue/falseShows the Black/White toggle in the UI.
accent / accentContrasthex or nullLeave null for the theme-optimised mint; set a hex to force one brand colour across both themes.
radiusnumber (px)Base corner radius.
fontFamilyCSS font stackApp-wide typeface (ships with the system stack).
followTelegramThemetrue/falseSync background/text colours with the user's Telegram theme.

Currency & commerce

KeyWhat it does
currency.code/symbol/position/decimals/thousands/decimalPrice formatting, e.g. $9.99 or 9,99 €.
commerce.taxRateTax as a decimal (0.08 = 8%).
commerce.shippingFlatFlat shipping charged when the cart has physical items.
commerce.freeShippingThresholdSubtotal at/above which shipping is free (0 disables).
commerce.maxQtyPerItemQuantity cap per line item.
commerce.promoCodesMap of codes to {type:'percentage'|'fixed', value, label}.

Feature flags

Every entry in config.features toggles a whole area on or off (UI and routes): onboarding, search, categories, wishlist, reviews, ratings, digitalProducts, promo, addresses, paymentMethods, notifications, languageSwitcher, admin. Set any to false to hide it everywhere.

Navigation & data

KeyWhat it does
nav.tabs[]The bottom tab bar — each {id,label,icon,href}. Reorder, rename or remove tabs here.
data.source'mock' (bundled catalog + localStorage) or 'api' (your backend).
data.apiBaseUrlBase URL used when source==='api'.
data.persistNamespacePrefix for all localStorage keys (default nova).
telegram.*enabled, expand, haptics, closingConfirmation — Telegram WebApp behaviour.

Theming & dark mode

All colours are CSS custom properties in assets/css/tokens.css. Light values live on :root; dark values on html[data-theme="light"]. To rebrand, either set config.theme.accent to your hex (fastest) or edit the tokens directly for full control.

/* assets/css/tokens.css */
html[data-theme="light"]{
  --accent:#3390EC;      /* your brand colour */
  --bg:#1A1A1A;          /* app background   */
  --card:#2C2C2E;        /* surfaces         */
  --text:#F2F2F7;
}
Cache-bustingAssets are versioned with a ?v=… query string. When you change a cached file, bump its ?v= in the HTML (and CACHE_NAME in sw.js if present) so the browser fetches the new version.

Localization

Languages are plain files under assets/js/i18n/locales/ — one per language. Adding a language takes three steps:

1

Copy a locale file

Duplicate en.js to xx.js (e.g. fr.js) and translate the values.

2

Register it

Import it in assets/js/i18n/index.js and add its code to config.locale.available.

3

Right-to-left?

If the language is RTL, add its code to config.locale.rtlLocales — layout mirrors automatically (Arabic ships as a working example).

Products & catalog

The bundled catalog lives in assets/js/data/catalog.js — an array of products and a list of categories. Edit it to sell your own items, or switch to your API (see Connect a backend).

// assets/js/data/catalog.js
{
  id:'p-aurora-buds', name:'Aurora Wireless Earbuds',
  price:89, type:'physical',            // 'physical' | 'digital'
  categoryId:'electronics', inStock:true, stock:37,
  rating:4.8, reviewCount:214, badges:['Bestseller'],
  emoji:'🎧', color:'#5B6CFF',          // generates a clean SVG placeholder
  description:'…', specs:{…}
}
No image hosting neededProducts render generated SVG placeholders from an emoji + colour, so the demo is 100% self-contained and resale-safe. Swap in your own image URLs any time by adding an image field.

Physical vs digital: digital items skip shipping and tax logic, and appear in the buyer's Downloads / license-key pages automatically.

Payments

Checkout runs through one guarded adapter — assets/js/core/payments.js — configured entirely from config.payments. Three real rails ship, plus Cash on Delivery:

RailHow it worksYou provide
Telegram Stars (XTR)Your bot backend creates an invoice link (Bot API createInvoiceLink, currency XTR); the app opens it with WebApp.openInvoice().providers.telegramStars.createInvoiceUrl
TON ConnectPay on-chain from any TON wallet via the TON Connect UI SDK.manifestUrl + recipientAddress, and uncomment the SDK script in checkout.html
StripeHosted Checkout Session or Payment Link (redirect — no card data touches the app).mode + checkoutUrl or paymentLinkUrl; limit with supportedCountries
Cash on DeliveryRecords a pending order — no gateway needed.Nothing.
Works out of the boxLeave a rail's fields blank and, with payments.demoSimulate:true, it resolves a simulated success so the storefront always completes. Fill the fields in to charge for real. Only publishable values/endpoints live in the client — keep secret keys and bot tokens on your server.
TON manifestBefore going live, host the included tonconnect-manifest.json at a public HTTPS URL and set providers.tonConnect.manifestUrl to it.

Admin panel

The admin/ folder is a full merchant dashboard (forced dark theme) with its own shell and one controller per page: orders, products (with CSV import/export), inventory, customers, analytics & reports, discounts, collections, gift cards, loyalty, Q&A moderation, payouts, wallets, broadcasts, templates, activity log, staff, integrations and settings. Reach it from Profile → Admin Panel or open admin/index.html.

Demo dataAdmin figures are computed from the current browser's localStorage plus seeded demo data. Point the data layer at your backend for live, shared numbers.

Deploy to Telegram

1

Upload over HTTPS

Put the contents of 01-html-css-js into your host's public web root (e.g. cPanel public_html). Telegram Mini Apps must be served over HTTPS.

2

Create a bot

In @BotFather send /newbot and follow the prompts to get your bot token.

3

Register the Mini App

Use /newapp (or Bot Settings → Menu Button / Web App) and paste your HTTPS URL. BotFather links your store to the bot.

4

Open & test

Launch the bot in Telegram and tap the menu button. Your store opens as a native Mini App with themed colours, haptics and the back button wired.

HTTPS is mandatoryTelegram refuses to load Mini Apps over plain HTTP. Most shared hosts include free Let's Encrypt SSL — enable it before registering the app.

Connect a backend

Pages never touch storage directly — they call dataService in assets/js/core/store.js. To use your own backend, set the data source and implement the API adapter methods:

// assets/js/config.js
data:{ source:'api', apiBaseUrl:'https://api.yourstore.com', persistNamespace:'nova' }

Then fill in the api adapter in store.js (get products, get/place orders, wishlist, addresses…). The mock adapter stays as a reference implementation, so the shape of every call is already spelled out for you.

Browser support

Targets modern evergreen browsers and the Telegram in-app WebView (iOS, Android, Desktop): latest Chrome, Edge, Firefox, Safari and Samsung Internet. Uses native ES modules, CSS custom properties, grid and flexbox — no polyfills required.

Troubleshooting & FAQ

The page is blank / nothing loads

You opened it as a file://… path. ES modules are blocked there. Serve over HTTP instead — use START-SERVER.bat/.command or python -m http.server and visit localhost.

My edits don't show up

Browser cache. Hard-refresh with Ctrl+Shift+R, and bump the asset's ?v= version string if you changed a cached file.

Payments just show a "demo" success

Expected until you configure a rail. Fill in the provider fields in config.payments (and add a backend endpoint where noted). See Payments.

Telegram features seem missing in my browser

They only exist inside Telegram. The kit detects this and falls back to browser equivalents so you can still develop and preview everything.

How do I add a page?

Copy an existing page.html + its assets/js/pages/page.js controller, rename both, and link the new page from a tab or a button.
